# Task 1 -- Manual QA Testing Report

## Overview

This folder contains the manual QA testing report prepared for the
Automation & QA Developer assessment.

The RealWorld demo application was tested, and five issues were
documented in the report.

## Issues Covered

The report documents issues related to:

1.  Registration accepting very short usernames and passwords.
2.  Registration/login not requiring email OTP verification.
3.  Article creation accepting whitespace-only or otherwise improperly
    validated input.
4.  Inconsistent title validation when editing an article.
5.  The Read More option appearing for a very short article preview.

## Report Contents

The QA report includes: - Bug descriptions and reproduction steps. -
Expected and actual results. - Severity and suspected causes. - Root
Cause Analysis for Issue #3. - Suggested improvements, including
trimming input and validating it on the backend.
